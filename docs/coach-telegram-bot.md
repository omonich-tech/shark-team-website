# Отдельный Telegram-бот тренеров SHARK TEAM

## Схема
- Родители: существующий `@sharkteam_uz_bot` → `/miniapp?role=parent`.
- Тренеры: отдельный бот (имя и username выбираются в BotFather) → `/miniapp?role=coach`.
- Backend и CRM: общие; разные секреты, разные Telegram webhooks и раздельные меню.
- В Mini App нет переключателя «Родитель / Тренер» — роль определяется точкой входа.
- У тренера дополнительно обязательно действующее имя пользователя и пароль от CRM. Проверка назначенных занятий на сервере сохранена.

## Подключение (нужно действие владельца в Telegram)
1. В Telegram открыть официальный `@BotFather` → `/newbot`, создать бота, выбрать имя и username. **Никому не отправлять токен в чат**.
2. В Vercel → проект `shark-team-website` → Settings → Environment Variables для Production установить `COACH_TELEGRAM_BOT_TOKEN` и `COACH_TELEGRAM_WEBHOOK_SECRET` (самостоятельно сгенерированная криптографически случайная строка, допустимые для Telegram символы A-Z, a-z, 0-9, _ и -).
3. Убедиться, что `NEXT_PUBLIC_APP_URL=https://sharkteam.uz`. Пересобрать Production, чтобы приложение увидело новые переменные.
4. Запустить `npm run telegram:coach:configure` в защищённой среде, где доступны эти переменные. Скрипт создаёт webhook `https://sharkteam.uz/api/telegram/coach-webhook` и команды start/menu только для нового бота. Не использовать родительский токен!
5. В новом боте нажать Start → «Открыть кабинет тренера». Войти под своей учётной записью CRM и проверить группу и журнал.
6. У родительского `@sharkteam_uz_bot` отправить `/start`: тренерских кнопок там больше нет.

## Ограничения первого подключения
- Бот тренеров пока запускает Mini App и не повторяет функции журнала в текстовых сообщениях.
- Telegram ID тренера ещё не связан с CoachAccount; отдельная аутентификация производится через действующие CRM-пароли и HttpOnly cookie. Привязку Telegram ID и выдачу доступа администратором можно сделать следующим этапом.
- Функции CRM и данные родителя не изменены. Без двух новых переменных отдельный бот отключён и возвращает HTTP 503.
